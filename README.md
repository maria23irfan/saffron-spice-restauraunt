# 🍽️ Saffron & Spice — Restaurant Website

Welcome to **Saffron & Spice**, a modern single-page restaurant website designed with **HTML and CSS**.

The website focuses on a warm, elegant restaurant experience with delicious food, featured dishes, and an easy-to-use navigation system.

## 🌟 Features

* 🏠 Modern hero/home section
* 🍔 Featured dishes section
* 📖 Restaurant story/about section
* 📅 Reservation section
* 🧭 Same-page navigation
* ✨ Smooth scrolling
* 📱 Responsive design for mobile devices
* 🖼️ High-quality food and restaurant imagery
* 🎨 Dark and gold restaurant-themed design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* Responsive Design
* CSS Flexbox
* CSS Grid
* CSS Background Images

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the website.

No additional software or installation is required.

## 🍴 Website Sections

### Home

Introduces Saffron & Spice with a large hero section and a call-to-action button.

### Menu

Displays some of the restaurant's featured dishes, including:

* Grilled Chicken
* Creamy Pasta
* Classic Burger

### About

Describes the restaurant's philosophy and approach to creating memorable meals.

### Reservation

Provides a call-to-action for customers who want to reserve a table.

This project was created as a **web design project** to practice HTML and CSS skills while creating a realistic restaurant website.
